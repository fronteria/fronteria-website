{{< objective >}}resolver una tarea de la semana y quedarse con una forma de repetir el proceso.{{< /objective >}}

{{< step number="1" title="Elijan una tarea segura y acotada" >}}
Elija una tarea de la semana sin datos sensibles: responder un correo difícil, resumir una reunión, recordar un pago, revisar ortografía, preparar seguimiento de embarques, resolver una fórmula, traducir un correo o crear una lista de verificación para un despacho. Sustituya nombres y cifras reales por ejemplos ficticios.
{{< /step >}}

{{< step number="2" title="Armen un pedido claro" >}}
Complete el mensaje con contexto, tarea y formato, y envíelo a la herramienta:

{{< prompt >}}
Eres asistente de [tipo de empresa o cargo].
Necesito [tarea].
El contexto es [qué pasó, para quién, datos que se pueden compartir].
Quiero que me entregues [formato: correo de máximo X líneas, tabla, lista, resumen].
Tono: [cordial, formal o firme].
{{< /prompt >}}
{{< /step >}}

{{< step number="3" title="Revisen antes de reutilizar" >}}
Antes de usar el resultado, pregúntese: ¿revisé cifras, fechas y nombres? ¿Compartí algún dato que no debía? El instructor y el apoyo pueden ayudar a adaptar el pedido.
{{< /step >}}

{{< reflection title="Mi próximo paso" >}}
¿Qué parte del pedido produjo una respuesta más útil? ¿Qué revisaré siempre antes de usar el resultado?
{{< /reflection >}}
