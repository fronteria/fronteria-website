{{< objective >}}identificar errores de redacción, tono, fechas, sumas y datos faltantes.{{< /objective >}}

{{< step number="1" title="Abra la carta de práctica" >}}
Abra [04 · Carta con errores (Word)](/recursos/ia-logistica-comercio-internacional/fundamentos/ejercicios/04_carta_con_errores.docx) o copie el texto en la herramienta.
{{< /step >}}

{{< step number="2" title="Pida una revisión explicada" >}}
Envíe el texto de la carta junto con este prompt:

{{< prompt >}}
Revisa esta carta de cobro. No me des solo la versión final: primero haz una lista de todo lo que encuentres (ortografía, tildes, tono, fechas, sumas, nombres inconsistentes, datos que faltan) y explica cada punto en una línea.
Después escribe la carta corregida con tono cordial y firme.
{{< /prompt >}}
{{< /step >}}

{{< step number="3" title="Decidan qué correcciones aceptar" >}}
Lea la carta usted misma. Compare los cambios y revise especialmente la fecha y la suma antes de decidir cuáles acepta.
{{< /step >}}

{{< reflection title="Criterio de revisión" >}}
¿Qué error fue más fácil de pasar por alto? ¿Qué corrección no aceptarían sin consultar la fuente?
{{< /reflection >}}
